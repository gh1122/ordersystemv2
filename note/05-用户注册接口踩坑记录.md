## 二、踩坑记录

### 坑 1：Mapper 用 class 定义，方法没有方法体

**报错**：
```
This method requires a body instead of a semicolon
```

**原因**：MyBatis 的 Mapper 应该定义为 `interface`，不是 `class`。
接口中的方法不需要方法体，MyBatis 会在运行时自动生成实现。

**解决**：
```java
// ❌ 错误
public class UserMapper {
    void insertUser(User user);  // 报错！
}

// ✅ 正确
public interface UserMapper {
    void insertUser(User user);  // OK
}
```

---

### 坑 2：Service 类没加 @Service 注解，启动失败

**报错**：
```
Field UserService in UserController required a bean of type 
'com.gh.ordersystem.service.UserService' that could not be found.
```

**原因**：`@Autowired` 是"让 Spring 帮我注入一个实例"，但 Spring 只认识有注解的类。
没有 `@Service`，Spring 不知道这个类需要被管理。

**解决**：在 Service 类上加 `@Service` 注解。

> 类比前端：就像你写了一个函数但忘了 `export`，别人 import 不到。

---

### 坑 3：Postman 报 415 Unsupported Media Type

**原因**：Postman 的 Body 格式选了 `Text`，请求头是 `text/plain`。
但 `@RequestBody` 需要 `Content-Type: application/json`。

**解决**：Postman 里 Body 选 `raw`，右侧格式选 `JSON`。

---

### 坑 4：插入成功后，id 返回 0 而不是数据库自增值

**原因**：数据库自增生成了 id=1，但 Java 对象不知道，因为没配置回填。

**解决**：`@Insert` 上加 `@Options`：
```java
@Insert("INSERT INTO t_user (username, password) VALUES (#{username}, #{password})")
@Options(useGeneratedKeys = true, keyProperty = "id")
void insertUser(User user);
```

> `useGeneratedKeys=true`：使用数据库生成的主键  
> `keyProperty="id"`：把生成的值填回 user.id

---

### 坑 5：create_time / update_time 为 null

**原因**：INSERT 语句只写了 username 和 password，没管时间字段。

**解决**：给数据库字段加默认值：
```sql
ALTER TABLE t_user 
  MODIFY create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  MODIFY update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP;
```

> 类比前端：就像表单里有些字段是"自动填充"的，不需要用户手动输入。

## 三、知识点总结

| 知识点 | 说明 |
|--------|------|
| `@Service` | 告诉 Spring 管理这个类，才能被 `@Autowired` 注入 |
| `@Mapper` | 告诉 MyBatis 这是一个 Mapper 接口，自动生成实现 |
| `@RequestBody` | 把 JSON 请求体转成 Java 对象 |
| `@NotBlank` + `@Size` | 参数校验注解，组合使用更保险 |
| `@Options` | MyBatis 插入后回填自增主键 |
| `@Valid` | 触发 DTO 的参数校验（本次还没加，后续补） |
| BCrypt 加密 | 密码必须加密存储，不能存明文（本次还没加，后续补） |
