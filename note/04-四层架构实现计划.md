# 04 - 四层架构实现计划

> 日期：2026-09-01

---

## 一、架构总览

```
前端请求
   ↓
 Controller 层（控制层）  → 接收请求，调用 Service
   ↓
  Service 层（业务层）    → 处理业务逻辑
   ↓
Repository 层（数据层）   → 访问数据库
   ↓
    数据库
```

---

## 二、各层职责

### Controller 层（控制层）

**职责**：接收 HTTP 请求，调用 Service，返回响应

**做什么**：
- 接收前端传来的参数（`@RequestParam`、`@PathVariable`、`@RequestBody`）
- 调用 Service 处理业务
- 把结果包装成统一格式返回

**不做什么**：
- ❌ 不写业务逻辑
- ❌ 不直接访问数据库

**前端类比**：路由处理函数 `(req, res) => { ... }`

---

### Service 层（业务层）

**职责**：处理核心业务逻辑，协调各组件

**做什么**：
- 业务规则校验（如：用户名是否重复）
- 调用 Repository 获取数据
- Entity → VO 转换（脱敏）
- 事务管理（`@Transactional`）

**不做什么**：
- ❌ 不直接处理 HTTP 请求
- ❌ 不包含 SQL 语句

**前端类比**：`utils/` 下的业务逻辑函数（如 `validateUser()`、`formatUserName()`）

---

### Repository 层（数据层）

**职责**：封装数据库操作

**做什么**：
- 执行 SQL（通过 MyBatis-Plus）
- 数据库表 ↔ Java 对象的映射
- 基础的 CRUD

**不做什么**：
- ❌ 不写业务逻辑
- ❌ 不处理 HTTP

**前端类比**：`api/` 下的请求函数（如 `getUserById()`、`createUser()`）

---

## 三、数据模型分层

在三层之间流转的数据对象不同，这是重点：

```
数据库表
   ↓ 查询
 Entity（实体类）     → 和数据库表一一对应，含所有字段（包括 password）
   ↓ 转换
 VO（视图对象）       → 返回给前端，去掉敏感字段（password 没了）
   ↓
  前端
```

| 类型 | 用途 | 包含字段 | 前端类比 |
|------|------|---------|---------|
| **Entity** | 数据库映射 | 所有字段（含 password、deleted） | 数据库返回的原始数据 |
| **DTO** | 接收前端参数 | 前端传来的字段（如登录时的 username + password） | 请求参数对象 |
| **VO** | 返回前端 | 脱敏后的字段（不含 password） | 前端展示的表格数据 |

## 四、完整请求流程示例

**场景**：前端发起请求 `GET /user/searchUser?id=1`

```
前端发起请求：GET /user/searchUser?id=1
          ↓
┌─────────────────────────────────────────────────────┐
│  Controller 层                                       │
│  1. 接收请求参数 id=1                                 │
│  2. 调用 userService.searchUser(id)                  │
└─────────────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────────────┐
│  Service 层                                          │
│  1. 调用 userRepository.searchUserById(id)           │
│  2. 拿到 Entity（含 password）                        │
│  3. 转换成 VO（去掉 password）                        │
│  4. 返回 UserVo                                      │
└─────────────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────────────┐
│  Repository 层                                       │
│  1. 模拟数据库查询                                    │
│  2. 返回完整 User 数据                                │
└─────────────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────────────┐
│  Controller 层                                       │
│  包装成 BaseVo.success(userVo) 返回 JSON              │
└─────────────────────────────────────────────────────┘
          ↓
前端收到响应：{ "success": true, "data": { "id": 1, "name": "guohao" } }
```

## 五、统一响应格式

所有接口返回统一的前端数据结构：

```json
{
  "success": true,           // 请求是否成功
  "data": { ... },           // 业务数据
  "message": "操作成功"       // 提示信息
}
```

对应 Java 类 `BaseVo<T>`：

```java
public class BaseVo<T> {
    private boolean success;   // 是否成功
    private T data;            // 业务数据
    private String message;    // 提示信息

    // 成功时调用
    public static <T> BaseVo<T> success(T data) { ... }

    // 失败时调用
    public static <T> BaseVo<T> fail(String message) { ... }
}
```

## 七、各层代码预览

### BaseVo.java

```java
package com.gh.ordersystem.model.vo;

import lombok.Data;

@Data
public class BaseVo<T> {
    private boolean success;
    private T data;
    private String message;

    public static <T> BaseVo<T> success(T data) {
        BaseVo<T> vo = new BaseVo<>();
        vo.setSuccess(true);
        vo.setData(data);
        vo.setMessage("操作成功");
        return vo;
    }

    public static <T> BaseVo<T> fail(String message) {
        BaseVo<T> vo = new BaseVo<>();
        vo.setSuccess(false);
        vo.setMessage(message);
        return vo;
    }
}
```

package com.gh.ordersystem.repository;

import java.util.HashMap;

### UserService.java

### UserServiceImpl.java

```java
package com.gh.ordersystem.service.impl;

import com.gh.ordersystem.model.entity.User;
import com.gh.ordersystem.model.vo.UserVo;
import com.gh.ordersystem.repository.UserRepository;
import com.gh.ordersystem.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class UserServiceImpl implements UserService {

    @Autowired
    private UserRepository userRepository;

    @Override
    public UserVo searchUser(Long id) {
        // 1. 从 Repository 获取 Entity
        User user = userRepository.searchUserById(id);

        // 2. 校验
        if (user == null) {
            return null;
        }

        // 3. Entity → VO 转换（脱敏：去掉 password）
        UserVo vo = new UserVo();
        vo.setId(user.getId());
        vo.setUsername(user.getUsername());
        vo.setNickname(user.getNickname());
        // 注意：password 不设置！

        return vo;
    }
}
```

### UserController.java

```java
package com.gh.ordersystem.controller;

import com.gh.ordersystem.model.vo.BaseVo;
import com.gh.ordersystem.model.vo.UserVo;
import com.gh.ordersystem.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class UserController {

    @Autowired
    private UserService userService;

    @GetMapping("/user/searchUser")
    public BaseVo<UserVo> searchUser(@RequestParam Long id) {
        UserVo userVo = userService.searchUser(id);
        if (userVo == null) {
            return BaseVo.fail("用户不存在");
        }
        return BaseVo.success(userVo);
    }
}
```

## 九、为什么用模拟数据？

本次目标：**先把四层架构的"骨架"搭通**

- Repository 用 `HashMap` 模拟数据库
- 跑通 Controller → Service → Repository 的调用链
- 验证统一响应格式、Entity → VO 转换

**下一步**：建表 + 集成 MyBatis-Plus，把模拟数据换成真实数据库操作。

## 十、Spring 注解速查

| 注解 | 作用 | 前端类比 |
|------|------|---------|
| `@RestController` | 标记控制器类 | 导出路由模块 |
| `@Service` | 标记业务类 | 标记"这是业务函数" |
| `@Repository` | 标记数据访问类 | 标记"这是 API 请求函数" |
| `@Autowired` | 自动注入依赖 | 自动 import 模块 |
| `@GetMapping` | 监听 GET 请求 | `router.get()` |
| `@RequestParam` | 获取查询参数 `?id=1` | `req.query.id` |
| `@RequestBody` | 获取请求体 JSON | `req.body` |
| `@Data`（Lombok） | 自动生成 getter/setter | 省去手写 `getXxx()` |
