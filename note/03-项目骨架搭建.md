### 4. 添加业务依赖

在 `pom.xml` 的 `<dependencies>` 中添加：

| 分类 | 依赖 | 用途 |
|------|------|------|
| ORM | `mybatis-plus-spring-boot3-starter` | 数据库操作（内含 MyBatis） |
| 驱动 | `mysql-connector-j` | MySQL 连接 |
| AOP | `spring-boot-starter-aop` | 面向切面编程 |
| 安全 | `spring-boot-starter-security` | 认证 + 授权 |
| 校验 | `spring-boot-starter-validation` | 参数校验 |
| 缓存 | `spring-boot-starter-data-redis` | Redis 客户端 |
| 消息 | `spring-kafka` | Kafka 消息队列 |
| 工具 | `lombok` | 简化代码（@Data 等） |
| 工具 | `hutool-all` | 国产工具库 |
| 鉴权 | `jjwt-api` / `jjwt-impl` / `jjwt-jackson` | JWT Token |

**版本统一管理**：在 `<properties>` 中声明版本号，依赖中用 `${变量名}` 引用：

```xml
<properties>
    <mybatis-plus.version>3.5.5</mybatis-plus.version>
    <hutool.version>5.8.27</hutool.version>
    <jjwt.version>0.12.5</jjwt.version>
</properties>
```

### 5. 配置文件格式转换

| 改动 | 改动前 | 改动后 |
|------|--------|--------|
| 配置文件 | `application.properties` | `application.yml` |
| 格式 | 扁平键值对 | 层级结构（更易维护） |

**application.yml 关键配置：**

```yaml
server:
  port: 8087              # 应用端口
  servlet:
    context-path: /api    # 所有接口前缀

spring:
  datasource:
    url: jdbc:mysql://localhost:3307/ordersystem  # MySQL 端口 3307
    username: root
    password: root
  data:
    redis:
      host: localhost
      port: 6379
  kafka:
    bootstrap-servers: localhost:9092

mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true   # 下划线转驼峰
    log-impl: ...StdOutImpl               # 打印 SQL 日志
```

### 6. Docker Compose 编排

文件：`docker-compose.yml`

| 服务 | 本地端口 | 容器端口 | 容器名 |
|------|---------|---------|--------|
| MySQL 8.0 | **3307** | 3306 | `ordersystem-mysql` |
| Redis 7 | 6379 | 6379 | `ordersystem-redis` |
| Kafka 3.7 | 9092 | 9092 | `ordersystem-kafka` |

> 注意：宿主机 3306 被本地 MySQL 占用，所以 Docker 的 MySQL 映射到 3307。

常用命令：
```powershell
docker compose up -d     # 启动
docker compose down      # 停止
docker compose logs -f   # 查看日志
```

## 二、踩坑记录

### 坑 1：starter 名称写错

错误：
```
'dependencies.dependency.version' for org.springframework.boot:spring-boot-starter-webmvc:jar is missing
```

原因：Spring Boot 没有 `spring-boot-starter-webmvc`，正确名称是 `spring-boot-starter-web`。

---

### 坑 2：MySQL 端口冲突

宿主机已有 MySQL 占用 3306，Docker 的 MySQL 需要映射到其他端口（3307）。

需要同步修改三处：
1. `docker-compose.yml` 的端口映射
2. `application.yml` 的连接地址
3. `note/02-Docker命令速查.md` 的端口表

---

### 坑 3：忘记加 @RestController

现象：访问接口返回 404。

原因：没有 `@RestController` 注解，Spring 不认为这个类是控制器，不会映射请求。
